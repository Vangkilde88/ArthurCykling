# Arthur Cycling – V1

Første visuelle prototype + live Intervals.icu forbindelse.

## Vercel environment variables

Projektet forventer:

- `intervals_api_key`
- `intervals_athlete_id`

Begge skal ligge i Vercel Environment Variables og må aldrig committes til GitHub.

## Første test

Efter deploy:
1. Åbn appen.
2. Under "Seneste aktivitet" skal chippen skifte fra `DEMO` til `LIVE DATA`.
3. Hvis den bliver stående på `DEMO`, åbn `/api/latest-activity` på dit Vercel-domæne for at se fejlbeskeden.
